绿立方农批交易平台 - 角色与核心流程

三大角色 + 交易闭环全景图

👥 三大角色关系

🛒

买家

餐厅/生鲜店/单位食堂等
浏览商品 → 下单付款 → 收货确认

🏪

供应商

农批商户/产地合作社等
发布商品 → 接单备货 → 发货 → 结算提现

🚚

司机

平台司机/供应商自有司机
接单取货 → 配送 → 签收确认

🔄 核心交易闭环流程

1
买家下单：浏览商品 → 加入购物车 → 选择配送时效 → 付款到平台担保
2
供应商接单备货：收到订单通知 → 确认接单 → 备货打包
3
司机配送：供应商发货 → 系统自动派单/抢单 → 司机取货 → 配送中 → 买家签收
4
收货确认 & 结算：买家确认收货（或超时自动确认）→ 平台扣除佣金 → 打款给供应商
