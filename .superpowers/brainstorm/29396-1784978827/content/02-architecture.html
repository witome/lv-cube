绿立方农批交易平台 - 系统架构设计

技术栈：uni-app (Vue3+TS) + NestJS (Node.js+TS) + MySQL + Redis

🏗️ 整体分层架构

🌐 客户端层
微信小程序（买家/供应商/司机 三端合一） + 运营管理 H5 后台
▼ HTTP / WebSocket
🚀 API 网关层 (NestJS)
统一鉴权、路由分发、限流、日志
▼ 内部模块调用
⚙️ 业务服务层 (NestJS Modules)
用户模块
商品模块
订单模块
支付模块
配送模块
结算模块
售后模块
消息通知
运营后台
▼ 数据访问
💾 数据存储层
MySQL (业务数据)
Redis (缓存/会话/队列)
对象存储 (图片)

📦 业务模块详细说明

👤 用户模块 注册登录、角色切换（买家/供应商/司机）、实名认证、资质审核、地址管理
📦 商品模块 品类管理、商品发布/上下架、规格属性（按品类模板）、库存管理、搜索筛选、商品评价
🛒 订单模块 购物车、下单（选择配送时效）、订单状态流转、取消订单、订单列表/详情
💳 支付/结算模块 微信支付（担保交易）、佣金计算、自动分账、提现、财务流水
🚚 配送模块 运费计算（固定+阶梯）、自动派单算法、抢单池、司机位置追踪、配送状态、自有司机管理
🔧 售后模块 退换货申请、举证上传、买卖协商、平台仲裁、退款处理
🔔 消息通知 订单状态推送、配送进度、微信模板消息、站内信
📊 运营后台 (H5) 用户审核、商品管理、订单监控、财务管理、数据统计、佣金配置、系统设置
